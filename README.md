# UNDANGAN MABAR — DAFA MUHYIDIN

Project undangan mabar digital bertema gaming yang sengaja dibuat dengan gaya personal/handmade:
- Full-screen opening
- Animasi dan micro-interaction
- Responsive HP/desktop
- Jadwal harian dan malam minggu
- Tombol konfirmasi "GAS LOGIN SEKARANG"
- Tidak membutuhkan backend

## Cara menjalankan
1. Extract folder.
2. Buka `index.html` di browser.
3. Kalau memakai VS Code, disarankan jalankan dengan Live Server.

## Mengubah isi
Semua teks utama ada di `index.html`.
Warna, ukuran, dan layout ada di `style.css`.
Interaksi tombol ada di `script.js`.
